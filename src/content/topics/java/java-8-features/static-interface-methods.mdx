## TL;DR

- Since Java 8, interfaces can contain **`static`** methods with concrete implementations.
- They belong to the interface itself, not to the instances of the classes that implement the interface.
- They are used to provide utility or helper methods directly within the interface.

## Concept

Historically, interfaces in Java couldn't have static methods. This led to a common design pattern where you would create an interface (e.g., `Collection`) and a separate companion utility class full of static helper methods (e.g., `Collections`).

Java 8 solved this. You can now put static helper methods directly inside the interface. This keeps related utility methods bundled tightly with the interface they serve, improving code organization and discoverability.

## Examples

```java
interface MathOperations {
    
    // Standard abstract method
    int operate(int a, int b);
    
    // Static method inside the interface
    static boolean isPositive(int number) {
        return number > 0;
    }
}

class Calculator implements MathOperations {
    @Override
    public int operate(int a, int b) {
        return a + b;
    }
}

public class StaticMethodExample {
    public static void main(String[] args) {
        Calculator calc = new Calculator();
        System.out.println("Sum: " + calc.operate(5, -2));
        
        // Calling the static interface method!
        // We use the Interface Name to invoke it, NOT the instance.
        boolean check = MathOperations.isPositive(5);
        System.out.println("Is positive? " + check);
        
        // This will NOT compile:
        // calc.isPositive(5); 
    }
}
```

## Interview Questions

Q: Are static interface methods inherited by implementing classes?
A: No. Unlike default methods, static methods are **never inherited**. You cannot call a static interface method using a reference to a class that implements the interface. You *must* invoke it using the interface name itself (e.g., `MyInterface.myStaticMethod()`).

Q: Why use a static interface method instead of a default method?
A: You use a `default` method when you want instances of implementing classes to inherit and use the behavior (and optionally override it). 
You use a `static` method when the logic is a generic utility function that doesn't rely on the object's instance state, and you don't want implementing classes to be able to override it.
