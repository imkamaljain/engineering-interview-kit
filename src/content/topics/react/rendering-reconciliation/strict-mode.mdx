## Interview Questions

**Q: Why does React Strict Mode deliberately render components twice in development mode?**
**A:** To help developers catch accidental side effects, impurities, or memory leaks in their Render phase logic. The Render phase must be completely pure. By rendering twice and throwing away the first result, React exposes bugs where a component was accidentally mutating external variables during render.
