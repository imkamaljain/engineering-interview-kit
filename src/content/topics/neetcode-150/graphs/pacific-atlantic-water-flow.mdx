## Problem Statement

There is an `m x n` rectangular island that borders both the **Pacific Ocean** and **Atlantic Ocean**.
- The **Pacific Ocean** touches the island's **left** and **top** edges.
- The **Atlantic Ocean** touches the island's **right** and **bottom** edges.

The island is partitioned into a grid of square cells. You are given an `m x n` integer matrix `heights` where `heights[r][c]` represents the height above sea level of the cell at coordinate `(r, c)`.

Rain water can flow to neighboring cells in the 4 cardinal directions (north, south, east, west) if the neighboring cell's height is **less than or equal to** the current cell's height. Water can flow from any cell adjacent to an ocean directly into that ocean.

Return a 2D list of grid coordinates `result` where `result[i] = [r_i, c_i]` denotes that rain water can flow from cell `(r_i, c_i)` to **both** the Pacific and Atlantic oceans.

**Example 1:**
```text
Input: heights = [
  [1,2,2,3,5],
  [3,2,3,4,4],
  [2,4,5,3,1],
  [6,7,1,4,5],
  [5,1,1,2,4]
]
Output: [[0,4],[1,3],[1,4],[2,2],[3,0],[3,1],[4,0]]
Explanation: The following cells can flow to both Pacific and Atlantic oceans:
- [0,4]: Flows to Pacific (top edge) and Atlantic (right edge)
- [1,3]: [1,3] -> [0,3] -> Pacific, and [1,3] -> [1,4] -> Atlantic
- [1,4]: Flows directly into both oceans
- [2,2]: [2,2] -> [1,2] -> [0,2] -> Pacific, and [2,2] -> [2,3] -> [2,4] -> Atlantic
- [3,0]: Flows directly into both oceans
- [3,1]: [3,1] -> [3,0] -> Pacific and Atlantic
- [4,0]: Flows directly into both oceans
```

**Example 2:**
```text
Input: heights = [[1]]
Output: [[0,0]]
```

**Constraints:**
- `m == heights.length`
- `n == heights[r].length`
- `1 <= m, n <= 200`
- `0 <= heights[r][c] <= 10^5`


## The Inversion: Reverse the Water Flow

### Why Starting from Every Cell Fails ($O(M^2 N^2)$)
A naive approach would run a separate traversal from every cell `(r, c)` to check if paths exist to both oceans.
- With $M, N \le 200$, there are $40,000$ cells.
- Each search could traverse up to $40,000$ cells.
- $40,000 \times 40,000 = 1.6 \times 10^9$ operations, leading to **Time Limit Exceeded (TLE)**.

### Reverse Flow: From Ocean Inward
Instead of simulating water flowing **downhill** from each cell to the oceans, we **invert the problem**:
> Simulate water flowing **uphill** from the ocean shorelines into the island!

1. If water can flow downhill from cell $A$ to cell $B$ ($\text{height}[A] \ge \text{height}[B]$), then working backwards from the ocean means moving from $B$ to $A$ where $\text{height}[A] \ge \text{height}[B]$.
2. We launch two independent traversals:
   - **Pacific Traversal:** Start along the **top** and **left** boundaries. Move into adjacent cells that are **greater than or equal to** the current cell's height. Mark them in a `pacific` visited matrix.
   - **Atlantic Traversal:** Start along the **bottom** and **right** boundaries. Move into adjacent cells that are **greater than or equal to** the current cell's height. Mark them in an `atlantic` visited matrix.
3. The answer is simply the **intersection**: any cell marked `true` in **both** `pacific` and `atlantic` can drain to both oceans!

## Solution: DFS Traversal

```javascript
/**
 * @param {number[][]} heights
 * @return {number[][]}
 */
var pacificAtlantic = function(heights) {
    if (!heights || heights.length === 0) return [];
    
    const rows = heights.length;
    const cols = heights[0].length;
    
    // Visited matrices for cells that can reach each ocean
    const pacific = Array.from({ length: rows }, () => new Uint8Array(cols));
    const atlantic = Array.from({ length: rows }, () => new Uint8Array(cols));
    
    const directions = [[-1, 0], [1, 0], [0, -1], [0, 1]];
    
    /**
     * DFS moving uphill into neighboring cells.
     * @param {number} r
     * @param {number} c
     * @param {Uint8Array[]} visited
     */
    const dfs = (r, c, visited) => {
        visited[r][c] = 1;
        
        for (const [dr, dc] of directions) {
            const nr = r + dr;
            const nc = c + dc;
            
            // In-bounds, unvisited, and moving uphill (neighbor >= current)
            if (
                nr >= 0 && nr < rows &&
                nc >= 0 && nc < cols &&
                !visited[nr][nc] &&
                heights[nr][nc] >= heights[r][c]
            ) {
                dfs(nr, nc, visited);
            }
        }
    };
    
    // 1. Seed top and bottom borders
    for (let c = 0; c < cols; c++) {
        dfs(0, c, pacific);                 // Top border (Pacific)
        dfs(rows - 1, c, atlantic);         // Bottom border (Atlantic)
    }
    
    // 2. Seed left and right borders
    for (let r = 0; r < rows; r++) {
        dfs(r, 0, pacific);                 // Left border (Pacific)
        dfs(r, cols - 1, atlantic);         // Right border (Atlantic)
    }
    
    // 3. Collect cells reachable by both oceans
    const result = [];
    for (let r = 0; r < rows; r++) {
        for (let c = 0; c < cols; c++) {
            if (pacific[r][c] && atlantic[r][c]) {
                result.push([r, c]);
            }
        }
    }
    
    return result;
};
```


## Complexity Analysis

- **Time Complexity:** $O(M \times N)$
  - Each cell is visited at most once during the Pacific DFS, and at most once during the Atlantic DFS.
  - Final matrix scan visits all $M \times N$ cells once.
  - Total time: $O(M \times N)$, executing in ~15ms for $200 \times 200$ grids.
- **Space Complexity:** $O(M \times N)$
  - $O(M \times N)$ space for the two `Uint8Array` visited matrices.
  - Recursion call stack can reach at most $O(M \times N)$ depth in the worst case.
