## Problem Statement

Given a reference of a node in a **connected undirected graph**, return a **deep copy** (clone) of the graph.

Each node in the graph contains a value (`val`) and a list (`neighbors`) of its neighbors:

```javascript
function _Node(val, neighbors) {
    this.val = val === undefined ? 0 : val;
    this.neighbors = neighbors === undefined ? [] : neighbors;
}
```

**Test Case Format:**
For simplicity, each node's value is the same as the node's index (1-indexed). The graph is represented in the test case using an adjacency list.

The given node will always be the first node with `val = 1`. You must return the copy of the given node as a reference to the cloned graph.

**Example 1:**
```text
Input: adjList = [[2,4],[1,3],[2,4],[1,3]]
Output: [[2,4],[1,3],[2,4],[1,3]]
Explanation: There are 4 nodes in the graph:
1st node (val = 1)'s neighbors are 2nd node (val = 2) and 4th node (val = 4).
2nd node (val = 2)'s neighbors are 1st node (val = 1) and 3rd node (val = 3).
3rd node (val = 3)'s neighbors are 2nd node (val = 2) and 4th node (val = 4).
4th node (val = 4)'s neighbors are 1st node (val = 1) and 3rd node (val = 3).
```

**Example 2:**
```text
Input: adjList = [[]]
Output: [[]]
Explanation: Note that the input contains one empty list. The graph consists of only one node with val = 1 and it does not have any neighbors.
```

**Example 3:**
```text
Input: adjList = []
Output: []
Explanation: This an empty graph, it does not have any nodes.
```

**Constraints:**
- The number of nodes in the graph is in the range `[0, 100]`.
- `1 <= Node.val <= 100`
- `Node.val` is unique for each node.
- There are no repeated edges and no self-loops in the graph.
- The graph is connected and all nodes can be visited starting from the given node.


## The Core Challenge: Cycles & Object References

A **Shallow Copy** (`const copy = node`) simply creates another reference pointing to the exact same physical memory address. If you alter any property on `copy`, the original graph is mutated.

A **Deep Copy** requires creating brand new objects (`new _Node(val)`) for every single node in the graph, with their `neighbors` arrays wired exclusively to the newly cloned nodes.

### The Infinite Cycle Trap
Because undirected graphs contain cycles ($1 \leftrightarrow 2$):
- Trying to clone Node 1 requires cloning its neighbor Node 2.
- Trying to clone Node 2 requires cloning its neighbor Node 1.
- Without cycle detection, this causes an infinite recursive loop resulting in a **Maximum Call Stack Size Exceeded**.

### The Solution: `oldToNew` Hash Map
We maintain a hash map (`Map<OriginalNode, ClonedNode>`):
1. **Memoize Clones:** The map records every node clone we have already instantiated.
2. **Cycle Prevention:** Whenever we encounter an old node that already exists in `oldToNew`, we do not recurse—we immediately return its existing clone!
3. **Critical Ordering:** We must register `oldToNew.set(node, copy)` **immediately after instantiation**, *before* iterating over its neighbors.

## Solution: DFS (Depth-First Search)

```javascript
/**
 * // Definition for a _Node.
 * function _Node(val, neighbors) {
 *    this.val = val === undefined ? 0 : val;
 *    this.neighbors = neighbors === undefined ? [] : neighbors;
 * };
 */

/**
 * @param {_Node} node
 * @return {_Node}
 */
var cloneGraph = function(node) {
    if (!node) return null;
    
    // Map: Old Node Reference -> New Cloned Node Reference
    const oldToNew = new Map();
    
    /**
     * @param {_Node} curr
     * @return {_Node}
     */
    const dfs = (curr) => {
        // If already cloned, return the cached clone
        if (oldToNew.has(curr)) {
            return oldToNew.get(curr);
        }
        
        // 1. Create a brand new clone
        const copy = new _Node(curr.val);
        
        // 2. IMPORTANT: Register clone in map BEFORE recursing neighbors
        oldToNew.set(curr, copy);
        
        // 3. Recursively clone all neighbors
        for (const neighbor of curr.neighbors) {
            copy.neighbors.push(dfs(neighbor));
        }
        
        return copy;
    };
    
    return dfs(node);
};
```


## Alternative: BFS (Breadth-First Search)

```javascript
/**
 * @param {_Node} node
 * @return {_Node}
 */
var cloneGraphBFS = function(node) {
    if (!node) return null;
    
    const oldToNew = new Map();
    const queue = [node];
    
    // Clone and register the root node
    oldToNew.set(node, new _Node(node.val));
    
    let head = 0;
    while (head < queue.length) {
        const curr = queue[head++];
        const currClone = oldToNew.get(curr);
        
        for (const neighbor of curr.neighbors) {
            // If neighbor not yet cloned, instantiate and enqueue
            if (!oldToNew.has(neighbor)) {
                oldToNew.set(neighbor, new _Node(neighbor.val));
                queue.push(neighbor);
            }
            
            // Link the cloned neighbor to the current cloned node
            currClone.neighbors.push(oldToNew.get(neighbor));
        }
    }
    
    return oldToNew.get(node);
};
```


## Complexity Analysis

- **Time Complexity:** $O(V + E)$
  - $V$ is the number of vertices (nodes) and $E$ is the number of edges.
  - Every node is visited and cloned exactly once ($O(V)$).
  - Every edge is traversed twice (once from each endpoint in an undirected graph) ($O(E)$).
- **Space Complexity:** $O(V)$
  - The `oldToNew` Map stores an entry for every node: $O(V)$.
  - **DFS Call Stack:** Bounded by the diameter / maximum path depth of the graph: $O(V)$.
  - **BFS Queue:** At most $O(V)$ nodes enqueued.
