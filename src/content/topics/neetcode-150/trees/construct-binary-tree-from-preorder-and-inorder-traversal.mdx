## Problem Statement

Given two integer arrays `preorder` and `inorder` where `preorder` is the preorder traversal of a binary tree and `inorder` is the inorder traversal of the same tree, construct and return the binary tree.

**Example:**
```text
Input: preorder = [3,9,20,15,7], inorder = [9,3,15,20,7]
Output: [3,9,20,null,null,15,7]
```

## Approach: Divide and Conquer

This problem is a fantastic puzzle that relies entirely on understanding the definitions of tree traversals:
- **Preorder (`Root -> Left -> Right`):** The very first element is *always* the root of the tree (or subtree)!
- **Inorder (`Left -> Root -> Right`):** Once you know what the root is, you can find it in this array. Everything to the left of it belongs to the left subtree, and everything to the right belongs to the right subtree.

**The Algorithm:**
1. **Base Case:** If the arrays are empty, return `null`.
2. **Find the Root:** The root's value is always `preorder[0]`. Create a new `TreeNode`.
3. **Find the Split:** Find the index of that root value in the `inorder` array (let's call it `mid`). 
4. **Divide:** 
   - The size of the left subtree is exactly `mid` elements.
   - We slice the next `mid` elements from `preorder` to pass to the left recursive call.
   - We slice the remaining elements from `preorder` to pass to the right recursive call.
5. **Conquer:** Recursively assign `root.left` and `root.right` using these sliced arrays.

## Mental Model

Let's trace how the arrays split in the first step. Notice how finding the root `3` in the `inorder` array instantly tells us exactly how many nodes belong to the left and right subtrees!

```text
Preorder: [ 3,  |  9,  |  20, 15, 7 ]
            ^      ^      ^
          Root    Left    Right Subtree (3 elements)
                 (1 elem)

Inorder:  [ 9,  |  3,  |  15, 20, 7 ]
            ^      ^      ^
           Left   Root    Right Subtree (3 elements)
         (1 elem)
```

With this knowledge, we can confidently split the arrays and recurse:
- `root.left = buildTree([9], [9])`
- `root.right = buildTree([20, 15, 7], [15, 20, 7])`

## Solution

```javascript
/**
 * Definition for a binary tree node.
 * function TreeNode(val, left, right) {
 *     this.val = (val===undefined ? 0 : val)
 *     this.left = (left===undefined ? null : left)
 *     this.right = (right===undefined ? null : right)
 * }
 */

function buildTree(preorder, inorder) {
    // Base case: no more nodes to process
    if (preorder.length === 0 || inorder.length === 0) {
        return null;
    }
    
    // The first element in preorder is ALWAYS the root
    const rootVal = preorder[0];
    const root = new TreeNode(rootVal);
    
    // Find where this root is in the inorder array to split the tree
    const mid = inorder.indexOf(rootVal);
    
    // Recursively build the left and right subtrees
    // Left: We take 'mid' number of elements
    root.left = buildTree(
        preorder.slice(1, mid + 1), 
        inorder.slice(0, mid)
    );
    
    // Right: We take the rest of the elements
    root.right = buildTree(
        preorder.slice(mid + 1), 
        inorder.slice(mid + 1)
    );
    
    return root;
}
```

*Note: The solution above is extremely intuitive but runs in $O(N^2)$ time because `indexOf` and `.slice()` take $O(N)$ time. In a strict interview, you can optimize this to $O(N)$ time and space by passing index pointers (`preStart`, `preEnd`, `inStart`, `inEnd`) instead of slicing arrays, and by pre-building a Hash Map (`val -> index`) of the `inorder` array so you can find `mid` in $O(1)$ time.*

## Complexity Analysis

- **Time Complexity:** $O(N^2)$ due to `indexOf` and `.slice()` inside the recursive calls. *(Can be optimized to $O(N)$ using index pointers and a Hash Map).*
- **Space Complexity:** $O(N^2)$ because `.slice()` creates new array copies at every step. *(Can be optimized to $O(N)$ for the recursion stack and Hash Map if using index pointers).*
