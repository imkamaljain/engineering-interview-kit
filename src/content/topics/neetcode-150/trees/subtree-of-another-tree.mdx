## Problem Statement

Given the roots of two binary trees `root` and `subRoot`, return `true` if there is a subtree of `root` with the same structure and node values of `subRoot` and `false` otherwise.

A subtree of a binary tree `tree` is a tree that consists of a node in `tree` and all of this node's descendants. The tree `tree` could also be considered as a subtree of itself.

**Example:**
```text
Input: root = [3,4,5,1,2], subRoot = [4,1,2]
Output: true
```

## Approach: DFS + Same Tree Helper

This problem is a direct extension of the **Same Tree** problem! 

To find if `subRoot` exists inside `root`, we simply need to traverse every single node in `root`. At every node we visit, we pause and ask: *"Is the tree starting right here identical to `subRoot`?"*

1. **The Helper:** We re-use the exact `isSameTree(p, q)` logic from LeetCode #100.
2. **The Main Traversal:** We use a standard Depth-First Search on `root`.
   - **Base Case 1:** If `subRoot` is `null`, it's technically a subtree of everything. Return `true`.
   - **Base Case 2:** If `root` is `null` (but `subRoot` isn't), we've hit the bottom of the main tree without finding a match. Return `false`.
   - **Check:** If `isSameTree(root, subRoot)` returns `true`, we found a match! Return `true`.
   - **Recurse:** If no match here, check if it exists in the left subtree `||` the right subtree.

## Solution

```javascript
/**
 * Definition for a binary tree node.
 * function TreeNode(val, left, right) {
 *     this.val = (val===undefined ? 0 : val)
 *     this.left = (left===undefined ? null : left)
 *     this.right = (right===undefined ? null : right)
 * }
 */

// Helper function from LeetCode #100
function isSameTree(p, q) {
    if (p === null && q === null) return true;
    if (p === null || q === null || p.val !== q.val) return false;
    return isSameTree(p.left, q.left) && isSameTree(p.right, q.right);
}

function isSubtree(root, subRoot) {
    // An empty tree is a subtree of any tree
    if (subRoot === null) return true;
    
    // We reached the bottom of the main tree without finding a match
    if (root === null) return false;
    
    // Does the tree starting at this exact node match subRoot?
    if (isSameTree(root, subRoot)) {
        return true;
    }
    
    // If not, check if it's hidden deeper in the left OR right subtrees
    return isSubtree(root.left, subRoot) || isSubtree(root.right, subRoot);
}
```

## Complexity Analysis

- **Time Complexity:** $O(R \cdot S)$ where $R$ is the number of nodes in `root` and $S$ is the number of nodes in `subRoot`. In the worst-case scenario (e.g., both trees are just a long line of identical nodes), we might call `isSameTree` (which takes $O(S)$) on every single node in $R$.
- **Space Complexity:** $O(H_R)$ where $H_R$ is the height of `root`. The maximum depth of the recursion call stack is bounded by the height of the main tree.
