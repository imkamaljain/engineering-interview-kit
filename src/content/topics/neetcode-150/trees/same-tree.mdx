## Problem Statement

Given the roots of two binary trees `p` and `q`, write a function to check if they are the same or not.

Two binary trees are considered the same if they are **structurally identical**, and the nodes have the **same value**.

**Example:**
```text
Input: p = [1,2], q = [1,null,2]
Output: false
```

## Approach: Simultaneous DFS (Recursive)

To check if two trees are identical, we simply need to traverse them at the exact same time, checking node-by-node.

For any given pair of nodes `p` and `q`:
1. **Base Case 1:** If both `p` and `q` are `null`, we've reached the bottom of both trees perfectly. Return `true`.
2. **Base Case 2:** If one is `null` but the other is not (structural mismatch), or if their values don't match (value mismatch), return `false`.
3. **Recursive Step:** If the current nodes match, we must ask the exact same question of their left children AND their right children. Both sides must return `true` for the trees to be considered identical.

## Solution

```javascript
/**
 * Definition for a binary tree node.
 * function TreeNode(val, left, right) {
 *     this.val = (val===undefined ? 0 : val)
 *     this.left = (left===undefined ? null : left)
 *     this.right = (right===undefined ? null : right)
 * }
 */

function isSameTree(p, q) {
    // Both nodes are null: structurally identical up to this point
    if (p === null && q === null) {
        return true;
    }
    
    // One is null and the other isn't, OR values don't match
    if (p === null || q === null || p.val !== q.val) {
        return false;
    }
    
    // The current nodes match! Now check the left and right subtrees
    return isSameTree(p.left, q.left) && isSameTree(p.right, q.right);
}
```

## Complexity Analysis

- **Time Complexity:** $O(\min(P, Q))$ where $P$ and $Q$ are the number of nodes in the two trees. The traversal will automatically stop as soon as it finds a mismatch, meaning the time is strictly bounded by the size of the smaller tree.
- **Space Complexity:** $O(\min(H_p, H_q))$ where $H_p$ and $H_q$ are the heights of the two trees. This is the memory used by the recursion call stack, which also bounds itself to the shortest path that hits a mismatch.
