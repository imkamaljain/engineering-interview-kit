## Problem Statement

Given an array of meeting time intervals consisting of start and end times `[[start_1, end_1], [start_2, end_2], ...]`, determine if a person could attend all meetings without overlap.

*(Note: On NeetCode, this problem is known as **Meeting Schedule**).*

> **Back-to-Back Rule:** If one meeting ends at time $t$ and another begins at the exact same time $t$ (e.g., `[0, 8]` and `[8, 10]`), they are **not** considered overlapping. A person can seamlessly transition from one meeting to the next.

**Example 1:**
```text
Input: intervals = [[0,30],[5,10],[15,20]]
Output: false
Explanation: [0,30] overlaps with both [5,10] and [15,20].
```

**Example 2:**
```text
Input: intervals = [[5,8],[9,15]]
Output: true
Explanation: The person finishes the first meeting at 8 and starts the second at 9.
```

**Example 3 (Back-to-Back):**
```text
Input: intervals = [[7,10],[2,4],[4,7]]
Output: true
Explanation: After sorting: [[2,4],[4,7],[7,10]]. No meetings overlap.
```

**Constraints:**
- `0 <= intervals.length <= 10^4`
- `intervals[i].length == 2`
- `0 <= start_i < end_i <= 10^6`


## Approach: Sort by Start Time

If the meetings are unsorted, checking whether *any* two meetings conflict would force us to compare all pairs in $O(N^2)$ time.

By **sorting intervals by their start times** in ascending order:
1. Every meeting appears chronologically.
2. We only need to check if the current meeting starts **before the immediately preceding meeting has finished**.

### The Overlap Condition:
For any meeting $i$ and its previous meeting $i - 1$:
$$\text{Conflict} \iff \text{intervals}[i].\text{start} < \text{intervals}[i - 1].\text{end}$$

If `intervals[i].start < intervals[i - 1].end`, return `false` immediately.
If the entire list is validated without finding any conflicts, return `true`.

## Solution

### 2D Array Representation (LeetCode standard)

```javascript
/**
 * @param {number[][]} intervals
 * @return {boolean}
 */
var canAttendMeetings = function(intervals) {
    // 1. Sort meetings by start time ascending
    intervals.sort((a, b) => a[0] - b[0]);

    // 2. Check adjacent pairs for overlap
    for (let i = 1; i < intervals.length; i++) {
        const prevEnd = intervals[i - 1][1];
        const currStart = intervals[i][0];

        // Strict inequality: back-to-back (currStart === prevEnd) is allowed
        if (currStart < prevEnd) {
            return false;
        }
    }

    return true;
};
```

### Interval Object Representation (NeetCode format)

```javascript
/**
 * Definition of Interval:
 * class Interval {
 *   constructor(start, end) {
 *     this.start = start;
 *     this.end = end;
 *   }
 * }
 */

class Solution {
    /**
     * @param {Interval[]} intervals
     * @return {boolean}
     */
    canAttendMeetings(intervals) {
        intervals.sort((a, b) => a.start - b.start);

        for (let i = 1; i < intervals.length; i++) {
            if (intervals[i].start < intervals[i - 1].end) {
                return false;
            }
        }

        return true;
    }
}
```


## Complexity Analysis

- **Time Complexity:** $O(N \log N)$
  - Sorting the array of $N$ meeting intervals requires $O(N \log N)$ time.
  - The subsequent linear check makes $N - 1$ comparisons, taking $O(N)$ time.
  - Overall time complexity: $O(N \log N)$.
- **Space Complexity:** $O(1)$ (or $O(\log N)$)
  - Sorting in-place uses $O(1)$ auxiliary memory (or $O(\log N)$ auxiliary call stack space used by the internal sorting algorithm).
