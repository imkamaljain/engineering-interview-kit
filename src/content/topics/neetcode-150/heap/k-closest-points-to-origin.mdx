## Problem Statement

Given an array of `points` where `points[i] = [xi, yi]` represents a point on the X-Y plane and an integer `k`, return the `k` closest points to the origin `(0, 0)`.

The distance between two points on the X-Y plane is the Euclidean distance:
$$\text{Distance} = \sqrt{(x_1 - x_2)^2 + (y_1 - y_2)^2}$$

Since the origin is `(0, 0)`, the distance simplifies to:
$$\text{Distance} = \sqrt{x^2 + y^2}$$

You may return the answer in **any order**. The answer is guaranteed to be **unique** (except for the order that it is in).

**Example 1:**
```text
Input: points = [[1,3],[-2,2]], k = 1
Output: [[-2,2]]
Explanation:
The distance between (1, 3) and the origin is sqrt(1^2 + 3^2) = sqrt(10).
The distance between (-2, 2) and the origin is sqrt((-2)^2 + 2^2) = sqrt(8).
Since sqrt(8) < sqrt(10), (-2, 2) is closer to the origin.
We only want the closest k = 1 points from the origin, so the answer is [[-2,2]].
```

**Example 2:**
```text
Input: points = [[3,3],[5,-1],[-2,4]], k = 2
Output: [[3,3],[-2,4]]
Explanation: The answer [[-2,4],[3,3]] would also be accepted.
```

## Approach: Max-Heap of Size K

### 1. Distance Simplification
Notice that $\sqrt{a} < \sqrt{b} \iff a < b$ for all non-negative numbers. Therefore, we do not need to calculate the expensive square root $\sqrt{x^2 + y^2}$. Comparing squared Euclidean distances $x^2 + y^2$ is mathematically equivalent and avoids floating-point inaccuracies.

### 2. The "Top K" Duality Trick
A common pitfall is instinctively reaching for a Min-Heap. However, maintaining a Min-Heap of all $N$ elements requires $O(N)$ space and $O(N \log N)$ or $O(N + K \log N)$ time.

Instead, to find the **$K$ Smallest / Closest** elements, we maintain a **Max-Heap capped at size $K$**:
- The Max-Heap holds our current "VIP club" of the $K$ closest candidates seen so far.
- The root of the Max-Heap is the **farthest** point (largest distance) currently inside this top-$K$ group.
- When inspecting each new point:
  1. Add it to the Max-Heap.
  2. If the heap size exceeds $K$, immediately dequeue the root. This ejects whichever point is farthest from the origin.
- After iterating through all $N$ points, the heap holds precisely the $K$ closest points!

## Solution

```javascript
/**
 * @param {number[][]} points
 * @param {number} k
 * @return {number[][]}
 */
var kClosest = function(points, k) {
    // Helper function to calculate squared Euclidean distance: x^2 + y^2
    const getDist = ([x, y]) => x * x + y * y;
    
    // Max-Heap prioritizes points with greater distance
    const maxHeap = new MaxPriorityQueue((point) => getDist(point));
    
    for (const point of points) {
        maxHeap.enqueue(point);
        
        // Keep heap size strictly <= k
        if (maxHeap.size() > k) {
            maxHeap.dequeue(); // Eject the farthest point among the k + 1 candidates
        }
    }
    
    // Drain remaining k points from heap
    const result = [];
    while (!maxHeap.isEmpty()) {
        result.push(maxHeap.dequeue());
    }
    
    return result;
};
```

## Alternative Approaches

### 1. Sorting ($O(N \log N)$ Time, $O(1)$ Extra Space)
Sort the entire array by distance in ascending order and slice the first $k$ items:
```javascript
var kClosest = function(points, k) {
    return points.sort((a, b) => (a[0]**2 + a[1]**2) - (b[0]**2 + b[1]**2)).slice(0, k);
};
```
*Great for concise code, but suboptimal when $K \ll N$ or in streaming scenarios.*

### 2. QuickSelect ($O(N)$ Average Time, $O(1)$ Space)
Using the QuickSelect partition algorithm (same as LeetCode #215), we can partition around a pivot distance until the pivot lands at index $k$. This achieves linear average time without extra heap memory, making it a great discussion point in interviews.

## Complexity Analysis

- **Time Complexity:** $O(N \log K)$
  - We process all $N$ points once.
  - Pushing and popping from a heap capped at size $K$ takes $O(\log K)$ time.
  - When $K \ll N$, $O(N \log K)$ is substantially faster than $O(N \log N)$.
- **Space Complexity:** $O(K)$
  - The Max-Heap stores at most $K + 1$ points at any time.
