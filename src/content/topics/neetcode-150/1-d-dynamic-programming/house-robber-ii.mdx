## Problem Statement

You are a professional robber planning to rob houses along a street. Each house has a certain amount of money stashed. All houses at this place are **arranged in a circle**. That means the first house is the neighbor of the last one. Meanwhile, adjacent houses have a security system connected, and it will automatically contact the police if two adjacent houses were broken into on the same night.

Given an integer array `nums` representing the amount of money of each house, return the **maximum amount of money you can rob tonight without alerting the police**.

**Example 1:**
```text
Input: nums = [2,3,2]
Output: 3
Explanation: You cannot rob house 1 (money = 2) and then rob house 3 (money = 2), 
             because they are adjacent neighbors in the circle.
```

**Example 2:**
```text
Input: nums = [1,2,3,1]
Output: 4
Explanation: Rob house 1 (money = 1) and then rob house 3 (money = 3).
Total amount you can rob = 1 + 3 = 4.
```

**Example 3:**
```text
Input: nums = [1,2,3]
Output: 3
```

**Constraints:**
- `1 <= nums.length <= 100`
- `0 <= nums[i] <= 1000`


## The Reduction: Breaking the Circular Cycle

### The Circular Conflict
In House Robber I, the street was a straight line. Now, the street forms a **circle**, which creates an extra constraint:
> **House `0` and House `n - 1` are adjacent neighbors.**

You can **never** rob both the first house and the last house simultaneously. This mutually exclusive conflict naturally splits the problem into two separate linear subproblems:

1. **Case 1: You may rob House `0`, but MUST skip House `n - 1`.**  
   Ignore the last house and solve the standard linear House Robber problem on:
   $$\text{nums}[0 \dots n - 2]$$

2. **Case 2: You may rob House `n - 1`, but MUST skip House `0`.**  
   Ignore the first house and solve the standard linear House Robber problem on:
   $$\text{nums}[1 \dots n - 1]$$

### What about robbing neither House `0` nor House `n - 1`?
If an optimal solution robs neither of them, that subset of houses is fully contained inside **both** `nums[0 ... n - 2]` and `nums[1 ... n - 1]`. Therefore, taking the maximum of both cases is guaranteed to capture the global optimum:

$$\text{result} = \max(\text{robLinear}(\text{nums}[0 \dots n - 2]),\; \text{robLinear}(\text{nums}[1 \dots n - 1]))$$

## Optimal Solution ($O(N)$ Time, $O(1)$ Space)

We reuse the $O(1)$ space rolling variable solution from House Robber I:

```javascript
/**
 * @param {number[]} nums
 * @return {number}
 */
var rob = function(nums) {
    const n = nums.length;
    
    // Base case: only 1 house
    if (n === 1) {
        return nums[0];
    }
    
    /**
     * Standard linear House Robber DP over range [start, end].
     * Uses O(1) rolling variables.
     */
    const robLinear = (start, end) => {
        let prev2 = 0;
        let prev1 = 0;
        
        for (let i = start; i <= end; i++) {
            const curr = Math.max(prev1, prev2 + nums[i]);
            prev2 = prev1;
            prev1 = curr;
        }
        
        return prev1;
    };
    
    // Case 1: Exclude last house (0 to n - 2)
    // Case 2: Exclude first house (1 to n - 1)
    return Math.max(
        robLinear(0, n - 2),
        robLinear(1, n - 1)
    );
};
```


## Complexity Analysis

| Metric | Complexity | Notes |
| :--- | :--- | :--- |
| **Time Complexity** | $O(N)$ | Two linear passes over subarrays of length $N - 1$. Total operations: $2 \times (N - 1) = O(N)$. |
| **Space Complexity** | $O(1)$ | Uses only two scalar rolling variables (`prev1`, `prev2`) during each linear pass. No extra arrays allocated. |


## Edge Cases

- **Single House (`nums = [7]`):** Must return `nums[0] = 7` immediately. Without the `n === 1` guard, `robLinear(0, -1)` would be invalid.
- **Two Houses (`nums = [2, 3]`):**
  - Case 1 `[0, 0]`: `nums[0] = 2`
  - Case 2 `[1, 1]`: `nums[1] = 3`
  - `Math.max(2, 3) = 3`.
- **Three Houses (`nums = [1, 2, 3]`):**
  - Case 1 `[0, 1]`: `Math.max(1, 2) = 2`
  - Case 2 `[1, 2]`: `Math.max(2, 3) = 3`
  - `Math.max(2, 3) = 3`.
- **All Zeros (`nums = [0, 0, 0]`):** Returns `0`.
