## Problem Statement

Given a string `s`, return the **number of palindromic substrings** in it.

A string is a **palindrome** when it reads the same backward as forward.

A **substring** is a contiguous sequence of characters within the string.

**Example 1:**
```text
Input: s = "abc"
Output: 3
Explanation: Three palindromic substrings: "a", "b", "c".
```

**Example 2:**
```text
Input: s = "aaa"
Output: 6
Explanation: Six palindromic substrings: "a", "a", "a", "aa", "aa", "aaa".
```

**Constraints:**
- `1 <= s.length <= 1000`
- `s` consists of lowercase English letters.


## The Intuition: From Longest to Total Count

This problem is the counting companion to _**Longest Palindromic Substring**_ where our goal was to find the **maximum length** palindrome. Here, our goal is to count **every single palindrome** that exists.

### Expand Around Center ($O(N^2)$ Time, $O(1)$ Space)
Because any palindrome expands symmetrically from its center, we can evaluate all $2N - 1$ possible centers:
- $N$ single-character centers (odd-length palindromes)
- $N - 1$ two-character centers (even-length palindromes)

For each center:
1. Start two pointers: `left = center1, right = center2`.
2. As long as `s[left] === s[right]`:
   - We have discovered **one valid palindrome** $\to$ increment `count++`.
   - Expand outward: `left--`, `right++`.
3. The moment `s[left] !== s[right]` or bounds are crossed, stop expanding that center (because any further expansion cannot form a palindrome).

## Solution 1: Expand Around Center ($O(N^2)$ Time, $O(1)$ Space) - Recommended

```javascript
/**
 * @param {string} s
 * @return {number}
 */
var countSubstrings = function(s) {
    let count = 0;
    
    /**
     * Expands outward from [left, right] and counts all valid palindromes.
     */
    const countFromCenter = (left, right) => {
        let palindromes = 0;
        
        while (left >= 0 && right < s.length && s[left] === s[right]) {
            palindromes++;
            left--;
            right++;
        }
        
        return palindromes;
    };
    
    for (let i = 0; i < s.length; i++) {
        // Odd-length palindromes (single-character center)
        count += countFromCenter(i, i);
        
        // Even-length palindromes (two-character center)
        count += countFromCenter(i, i + 1);
    }
    
    return count;
};
```


## Solution 2: 2D Dynamic Programming Tabulation ($O(N^2)$ Time, $O(N^2)$ Space)

Using interval dynamic programming where `dp[i][j]` indicates whether `s[i...j]` is a palindrome:

```javascript
/**
 * @param {string} s
 * @return {number}
 */
var countSubstringsDP = function(s) {
    const n = s.length;
    let count = 0;
    
    // dp[i][j] is true if substring s[i..j] is a palindrome
    const dp = Array.from({ length: n }, () => new Uint8Array(n));
    
    // Process from bottom to top so that dp[i + 1][j - 1] is precomputed
    for (let i = n - 1; i >= 0; i--) {
        for (let j = i; j < n; j++) {
            if (s[i] === s[j] && (j - i <= 2 || dp[i + 1][j - 1])) {
                dp[i][j] = 1;
                count++;
            }
        }
    }
    
    return count;
};
```


## Complexity Analysis

| Approach | Time Complexity | Space Complexity | Notes |
| :--- | :--- | :--- | :--- |
| **Expand Around Center** | $O(N^2)$ | $O(1)$ | Optimal. Evaluates $2N - 1$ centers with zero array allocation. |
| **2D Dynamic Programming** | $O(N^2)$ | $O(N^2)$ | Tabulates all substring intervals in an $N \times N$ matrix. |
| **Manacher's Algorithm** | $O(N)$ | $O(N)$ | Advanced linear-time counting algorithm. |


## Edge Cases

- **Single Character (`s = "a"`):** Evaluates `i = 0`; returns `1`.
- **All Distinct Characters (`s = "abc"`):** Only length-1 substrings match; returns `s.length = 3`.
- **All Identical Characters (`s = "aaaa"`):** Every possible substring is a palindrome. For length $N$, formula is $\frac{N(N+1)}{2}$. For $N = 4$, returns $\frac{4 \times 5}{2} = 10$.
- **Even-Length Mirror (`s = "abba"`):** Returns `6` (`"a"`, `"b"`, `"b"`, `"a"`, `"bb"`, `"abba"`).
