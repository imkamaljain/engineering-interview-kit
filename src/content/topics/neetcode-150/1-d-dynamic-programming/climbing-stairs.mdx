## Problem Statement

You are climbing a staircase. It takes `n` steps to reach the top.

Each time you can either climb `1` or `2` steps. In how many distinct ways can you climb to the top?

**Example 1:**
```text
Input: n = 2
Output: 2
Explanation: There are two ways to climb to the top:
1. 1 step + 1 step
2. 2 steps
```

**Example 2:**
```text
Input: n = 3
Output: 3
Explanation: There are three ways to climb to the top:
1. 1 step + 1 step + 1 step
2. 1 step + 2 steps
3. 2 steps + 1 step
```

**Constraints:**
- `1 <= n <= 45`


## The Dynamic Programming Intuition

### 1. Optimal Substructure
To reach step `n`, your very last move must be one of two possibilities:
- You took a **1-step climb** from step `n - 1`.
- You took a **2-step climb** from step `n - 2`.

Because these two sets of paths are mutually exclusive and collectively exhaustive, the total number of distinct ways to reach step `n` is simply the sum of both:

$$\text{ways}(n) = \text{ways}(n - 1) + \text{ways}(n - 2)$$

This is identical to the famous **Fibonacci Sequence**:
- $\text{ways}(1) = 1$ (paths: `[1]`)
- $\text{ways}(2) = 2$ (paths: `[1+1]`, `[2]`)
- $\text{ways}(3) = 1 + 2 = 3$
- $\text{ways}(4) = 2 + 3 = 5$
- $\text{ways}(5) = 3 + 5 = 8$

### 2. Overlapping Subproblems
A naive recursive solution splits every call into two branches, creating an exponential call tree ($O(2^n)$ operations). Notice how `ways(3)` and `ways(2)` are recomputed over and over:
- To compute `ways(5)`: needs `ways(4)` and `ways(3)`.
- To compute `ways(4)`: needs `ways(3)` and `ways(2)`.

By storing previously computed results (**Memoization**) or computing sequentially from step 1 up to `n` (**Tabulation**), we solve every distinct subproblem exactly once in $O(N)$ time.

## Solution 1: Space-Optimized DP ($O(N)$ Time, $O(1)$ Space) - Recommended

Because computing the current step only requires the immediate two preceding steps, we do not need an array of size $N$. Two variables suffice:

```javascript
/**
 * @param {number} n
 * @return {number}
 */
var climbStairs = function(n) {
    // Base cases
    if (n <= 2) {
        return n;
    }
    
    // prev2 corresponds to ways(1), prev1 corresponds to ways(2)
    let prev2 = 1;
    let prev1 = 2;
    
    for (let i = 3; i <= n; i++) {
        const curr = prev1 + prev2;
        prev2 = prev1;
        prev1 = curr;
    }
    
    return prev1;
};
```


## Solution 2: Bottom-Up Tabulation ($O(N)$ Time, $O(N)$ Space)

An explicit 1D array (`dp`) stores the answer for every step from `1` to `n`:

```javascript
/**
 * @param {number} n
 * @return {number}
 */
var climbStairsTabulation = function(n) {
    if (n <= 2) return n;
    
    const dp = new Int32Array(n + 1);
    dp[1] = 1;
    dp[2] = 2;
    
    for (let i = 3; i <= n; i++) {
        dp[i] = dp[i - 1] + dp[i - 2];
    }
    
    return dp[n];
};
```


## Solution 3: Top-Down Memoization ($O(N)$ Time, $O(N)$ Space)

Recursive approach with caching:

```javascript
/**
 * @param {number} n
 * @return {number}
 */
var climbStairsMemo = function(n) {
    const memo = new Map();
    
    const dfs = (step) => {
        if (step <= 2) return step;
        if (memo.has(step)) return memo.get(step);
        
        const ways = dfs(step - 1) + dfs(step - 2);
        memo.set(step, ways);
        return ways;
    };
    
    return dfs(n);
};
```


## Complexity Analysis

| Approach | Time Complexity | Space Complexity | Notes |
| :--- | :--- | :--- | :--- |
| **Space-Optimized (Rolling)** | $O(N)$ | $O(1)$ | Optimal. Tracks only `prev1` and `prev2` without allocating arrays. |
| **Bottom-Up Tabulation** | $O(N)$ | $O(N)$ | Iterative array pass; easy to inspect subproblem values. |
| **Top-Down Memoization** | $O(N)$ | $O(N)$ | Recursion call stack + hash map takes $O(N)$ memory. |
| **Naive Recursion** | $O(2^N)$ | $O(N)$ | Exponential time; triggers TLE for $N \ge 40$. |


## Edge Cases

- **Single Step (`n = 1`):** Returns `1` directly without entering the loop.
- **Two Steps (`n = 2`):** Returns `2` directly (`[1+1]` and `[2]`).
- **Maximum Bound (`n = 45`):** Returns `1,836,311,903`, which fits comfortably within standard 32-bit signed integer limits ($< 2^{31} - 1$).
