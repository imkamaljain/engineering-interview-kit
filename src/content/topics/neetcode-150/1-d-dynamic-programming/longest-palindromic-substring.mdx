## Problem Statement

Given a string `s`, return the **longest palindromic substring** in `s`.

A **palindrome** is a string that reads the same forward and backward. A **substring** is a contiguous sequence of characters within a string.

**Example 1:**
```text
Input: s = "babad"
Output: "bab"
Explanation: "aba" is also a valid answer.
```

**Example 2:**
```text
Input: s = "cbbd"
Output: "bb"
```

**Constraints:**
- `1 <= s.length <= 1000`
- `s` consists of only digits and English letters.


## The Two Core Approaches

### Approach 1: Expand Around Center ($O(N^2)$ Time, $O(1)$ Space) - Recommended
A palindrome is symmetric and mirrors around its center:
- **Odd-length palindromes** have a single character at the center (e.g. `"aba"` centered on `'b'`).
- **Even-length palindromes** have their center between two adjacent characters (e.g. `"abba"` centered between `'b'` and `'b'`).

For a string of length $N$, there are exactly $2N - 1$ potential centers ($N$ single-character centers and $N - 1$ two-character centers):
1. For each center, expand outward (`left--`, `right++`) as long as the boundary characters match (`s[left] === s[right]`).
2. Record the longest valid palindrome encountered.
3. Requires **$O(1)$ auxiliary space** because no table or recursion stack is allocated.

---

### Approach 2: Dynamic Programming Table ($O(N^2)$ Time, $O(N^2)$ Space)
A substring `s[i...j]` is a palindrome if and only if:
1. The endpoint characters match: `s[i] === s[j]`.
2. The inner substring `s[i + 1 ... j - 1]` is also a palindrome (or the substring has length $\le 2$, meaning `j - i <= 2`).

$$\text{dp}[i][j] = (s[i] == s[j]) \;\land\; (j - i \le 2 \;\lor\; \text{dp}[i + 1][j - 1])$$

While this uses $O(N^2)$ memory, understanding this interval DP transition is essential as it forms the template for harder palindrome problems (like *Palindromic Substrings* and *Longest Palindromic Subsequence*).

## Solution 1: Expand Around Center ($O(N^2)$ Time, $O(1)$ Space) - Recommended

```javascript
/**
 * @param {string} s
 * @return {string}
 */
var longestPalindrome = function(s) {
    if (!s || s.length <= 1) return s;
    
    let start = 0;
    let maxLen = 1;
    
    /**
     * Expands outward from [left, right] while characters match.
     * Updates global start and maxLen.
     */
    const expand = (left, right) => {
        while (left >= 0 && right < s.length && s[left] === s[right]) {
            const currentLen = right - left + 1;
            if (currentLen > maxLen) {
                maxLen = currentLen;
                start = left;
            }
            left--;
            right++;
        }
    };
    
    for (let i = 0; i < s.length; i++) {
        // Odd-length palindromes (centered at index i)
        expand(i, i);
        
        // Even-length palindromes (centered between index i and i + 1)
        expand(i, i + 1);
    }
    
    return s.substring(start, start + maxLen);
};
```


## Solution 2: 2D Dynamic Programming ($O(N^2)$ Time, $O(N^2)$ Space)

```javascript
/**
 * @param {string} s
 * @return {string}
 */
var longestPalindromeDP = function(s) {
    const n = s.length;
    if (n <= 1) return s;
    
    // dp[i][j] will be true if substring s[i..j] is a palindrome
    const dp = Array.from({ length: n }, () => new Uint8Array(n));
    
    let start = 0;
    let maxLen = 1;
    
    // Iterate backwards for i to ensure dp[i + 1][j - 1] is already computed
    for (let i = n - 1; i >= 0; i--) {
        for (let j = i; j < n; j++) {
            if (s[i] === s[j] && (j - i <= 2 || dp[i + 1][j - 1])) {
                dp[i][j] = 1;
                
                const currentLen = j - i + 1;
                if (currentLen > maxLen) {
                    maxLen = currentLen;
                    start = i;
                }
            }
        }
    }
    
    return s.substring(start, start + maxLen);
};
```


## Complexity Analysis

| Approach | Time Complexity | Space Complexity | Notes |
| :--- | :--- | :--- | :--- |
| **Expand Around Center** | $O(N^2)$ | $O(1)$ | Optimal memory. Evaluates $2N - 1$ centers with zero array allocation. |
| **2D Dynamic Programming** | $O(N^2)$ | $O(N^2)$ | Fills an $N \times N$ lookup table. Clear recurrence foundation. |
| **Manacher's Algorithm** | $O(N)$ | $O(N)$ | Advanced linear-time algorithm utilizing palindrome symmetry radii. |


## Edge Cases

- **Single Character (`s = "a"`):** Returns `"a"` immediately.
- **Two Identical Characters (`s = "bb"`):** Even-length center expands to `"bb"`.
- **Two Distinct Characters (`s = "ab"`):** Max length remains 1; returns `"a"`.
- **All Same Characters (`s = "aaaa"`):** Expands completely to the full length `"aaaa"`.
- **Longest Palindrome at Extremes:** Accurately catches palindromes anchored at index `0` or index `n - 1`.
