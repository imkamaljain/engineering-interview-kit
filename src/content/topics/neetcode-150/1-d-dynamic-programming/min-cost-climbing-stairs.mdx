## Problem Statement

You are given an integer array `cost` where `cost[i]` is the cost of the `i`-th step on a staircase. Once you pay the cost, you can either climb `1` or `2` steps.

You can either start from the step with index `0`, or the step with index `1`.

Return the **minimum cost to reach the top of the floor**.

> **Note:** The "top of the floor" is at index `n = cost.length`, which is one level past the final index `cost.length - 1`.

**Example 1:**
```text
Input: cost = [10,15,20]
Output: 15
Explanation: You will start at index 1.
- Pay 15 and climb two steps to reach the top.
The total cost is 15.
```

**Example 2:**
```text
Input: cost = [1,100,1,1,1,100,1,1,100,1]
Output: 6
Explanation: You will start at index 0.
- Pay 1 and climb two steps to reach index 2.
- Pay 1 and climb two steps to reach index 4.
- Pay 1 and climb two steps to reach index 6.
- Pay 1 and climb one step to reach index 7.
- Pay 1 and climb two steps to reach index 9.
- Pay 1 and climb one step to reach the top floor.
The total cost is 6.
```

**Constraints:**
- `2 <= cost.length <= 1000`
- `0 <= cost[i] <= 999`


## The Dynamic Programming Intuition

### Defining the Target and Subproblems
Let $n = \text{cost.length}$. The goal is to calculate the minimum cost to reach step $n$ (the top of the floor).

To step onto floor $i$, you must come from one of two places:
1. You were at step $i - 1$, paid $\text{cost}[i - 1]$, and took a **1-step jump**.
2. You were at step $i - 2$, paid $\text{cost}[i - 2]$, and took a **2-step jump**.

Therefore, the minimum cost to reach step $i$ is:

$$\text{dp}[i] = \min(\text{dp}[i - 1] + \text{cost}[i - 1],\; \text{dp}[i - 2] + \text{cost}[i - 2])$$

### Base Cases
Because you can start at either index `0` or index `1` for free:
- $\text{dp}[0] = 0$ (cost to reach step 0)
- $\text{dp}[1] = 0$ (cost to reach step 1)

Starting from $i = 2$ up to $n$, we iteratively compute the cheapest way to reach each subsequent step.

## Solution 1: Space-Optimized DP ($O(N)$ Time, $O(1)$ Space) - Recommended

Just like *Climbing Stairs*, computing step $i$ only depends on the previous two values ($\text{dp}[i - 1]$ and $\text{dp}[i - 2]$). We can maintain two rolling variables:

```javascript
/**
 * @param {number[]} cost
 * @return {number}
 */
var minCostClimbingStairs = function(cost) {
    const n = cost.length;
    
    // Minimum cost to reach step 0 and step 1
    let prev2 = 0;
    let prev1 = 0;
    
    for (let i = 2; i <= n; i++) {
        const curr = Math.min(
            prev1 + cost[i - 1], // Coming from step i - 1
            prev2 + cost[i - 2]  // Coming from step i - 2
        );
        prev2 = prev1;
        prev1 = curr;
    }
    
    return prev1;
};
```


## Solution 2: Bottom-Up Tabulation ($O(N)$ Time, $O(N)$ Space)

Using an explicit DP array of size $n + 1$:

```javascript
/**
 * @param {number[]} cost
 * @return {number}
 */
var minCostClimbingStairsTabulation = function(cost) {
    const n = cost.length;
    const dp = new Int32Array(n + 1);
    
    // dp[0] = 0 and dp[1] = 0 (free starting steps)
    dp[0] = 0;
    dp[1] = 0;
    
    for (let i = 2; i <= n; i++) {
        dp[i] = Math.min(
            dp[i - 1] + cost[i - 1],
            dp[i - 2] + cost[i - 2]
        );
    }
    
    return dp[n];
};
```


## Solution 3: Top-Down Memoization ($O(N)$ Time, $O(N)$ Space)

Recursive approach with memoization:

```javascript
/**
 * @param {number[]} cost
 * @return {number}
 */
var minCostClimbingStairsMemo = function(cost) {
    const memo = new Map();
    
    const minCostToReach = (i) => {
        // Can start at index 0 or 1 for free
        if (i <= 1) return 0;
        if (memo.has(i)) return memo.get(i);
        
        const ans = Math.min(
            minCostToReach(i - 1) + cost[i - 1],
            minCostToReach(i - 2) + cost[i - 2]
        );
        memo.set(i, ans);
        return ans;
    };
    
    return minCostToReach(cost.length);
};
```


## Complexity Analysis

| Approach | Time Complexity | Space Complexity | Notes |
| :--- | :--- | :--- | :--- |
| **Space-Optimized (Rolling)** | $O(N)$ | $O(1)$ | Optimal. Only keeps `prev1` and `prev2` in memory. |
| **Bottom-Up Tabulation** | $O(N)$ | $O(N)$ | Explicit `dp` array tracking cost to reach every step. |
| **Top-Down Memoization** | $O(N)$ | $O(N)$ | Recursion stack and cache take $O(N)$ memory. |


## Edge Cases

- **Minimum Length (`cost.length == 2`):** e.g., `cost = [10, 15]`. `i = 2` calculates `Math.min(0 + 15, 0 + 10) = 10`.
- **Zero Cost Steps (`cost = [0, 0, 0, 0]`):** Returns `0`.
- **Large and Small Alternating (`cost = [1, 100, 1, 1, 100, 1]`):** The algorithm reliably leaps over every expensive step of cost `100` by utilizing 2-step jumps.
