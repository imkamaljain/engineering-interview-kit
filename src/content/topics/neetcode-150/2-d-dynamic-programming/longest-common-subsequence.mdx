## Problem Statement

Given two strings `text1` and `text2`, return the length of their **longest common subsequence**. If there is no common subsequence, return `0`.

A **subsequence** of a string is a new string generated from the original string with some characters (can be none) deleted without changing the relative order of the remaining characters.
- For example, `"ace"` is a subsequence of `"abcde"`.

A **common subsequence** of two strings is a subsequence that is common to both strings.

**Example 1:**
```text
Input: text1 = "abcde", text2 = "ace" 
Output: 3  
Explanation: The longest common subsequence is "ace" and its length is 3.
```

**Example 2:**
```text
Input: text1 = "abc", text2 = "abc"
Output: 3
Explanation: The longest common subsequence is "abc" and its length is 3.
```

**Example 3:**
```text
Input: text1 = "abc", text2 = "def"
Output: 0
Explanation: There is no such common subsequence, so the result is 0.
```

**Constraints:**
- `1 <= text1.length, text2.length <= 1000`
- `text1` and `text2` consist of only lowercase English characters.


## The 2D Dynamic Programming Formulation

### Defining the State
Let $\text{dp}[i][j]$ be the length of the longest common subsequence between:
- Prefix `text1[0 ... i - 1]` (length $i$)
- Prefix `text2[0 ... j - 1]` (length $j$)

The dimensions of our grid are $(m + 1) \times (n + 1)$, where $m = \text{text1.length}$ and $n = \text{text2.length}$.

### Base Cases
If either string is empty (length 0), the LCS is trivially 0:
- $\text{dp}[0][j] = 0$ for all $0 \le j \le n$
- $\text{dp}[i][0] = 0$ for all $0 \le i \le m$

### State Transitions
When comparing character $\text{text1}[i - 1]$ with $\text{text2}[j - 1]$:

1. **Match ($\text{text1}[i - 1] == \text{text2}[j - 1]$):**
   - Both characters match and extend the LCS by 1!
   - We add 1 to the best result of the prefixes excluding both characters (the diagonal neighbor):
     $$\text{dp}[i][j] = 1 + \text{dp}[i - 1][j - 1]$$

2. **Mismatch ($\text{text1}[i - 1] \ne \text{text2}[j - 1]$):**
   - We cannot match both characters.
   - We choose the best outcome between skipping $\text{text1}[i - 1]$ (from above) or skipping $\text{text2}[j - 1]$ (from left):
     $$\text{dp}[i][j] = \max(\text{dp}[i - 1][j],\; \text{dp}[i][j - 1])$$

## Solution 1: Space-Optimized 1D DP ($O(M \cdot N)$ Time, $O(\min(M, N))$ Space) - Recommended

Because row $i$ only requires values from row $i - 1$, we can compress the space into a single 1D array by caching the diagonal value `prevDiag`:

```javascript
/**
 * @param {string} text1
 * @param {string} text2
 * @return {number}
 */
var longestCommonSubsequence = function(text1, text2) {
    // Ensure text2 is the shorter string to minimize space to O(min(m, n))
    if (text1.length < text2.length) {
        return longestCommonSubsequence(text2, text1);
    }
    
    const m = text1.length;
    const n = text2.length;
    const dp = new Int32Array(n + 1);
    
    for (let i = 1; i <= m; i++) {
        let prevDiag = 0; // Represents dp[i - 1][j - 1]
        
        for (let j = 1; j <= n; j++) {
            const temp = dp[j]; // Cache dp[i - 1][j] before overwriting
            
            if (text1[i - 1] === text2[j - 1]) {
                dp[j] = 1 + prevDiag;
            } else {
                dp[j] = Math.max(dp[j], dp[j - 1]);
            }
            
            prevDiag = temp; // Advances to next column's diagonal
        }
    }
    
    return dp[n];
};
```


## Solution 2: Full 2D Grid DP ($O(M \cdot N)$ Time, $O(M \cdot N)$ Space)

Direct implementation of the 2D matrix recurrence:

```javascript
/**
 * @param {string} text1
 * @param {string} text2
 * @return {number}
 */
var longestCommonSubsequence2D = function(text1, text2) {
    const m = text1.length;
    const n = text2.length;
    
    const dp = Array.from({ length: m + 1 }, () => new Int32Array(n + 1));
    
    for (let i = 1; i <= m; i++) {
        for (let j = 1; j <= n; j++) {
            if (text1[i - 1] === text2[j - 1]) {
                dp[i][j] = 1 + dp[i - 1][j - 1];
            } else {
                dp[i][j] = Math.max(dp[i - 1][j], dp[i][j - 1]);
            }
        }
    }
    
    return dp[m][n];
};
```


## Solution 3: Top-Down Recursion with Memoization

```javascript
/**
 * @param {string} text1
 * @param {string} text2
 * @return {number}
 */
var longestCommonSubsequenceMemo = function(text1, text2) {
    const memo = new Map();
    
    const helper = (i, j) => {
        if (i === text1.length || j === text2.length) return 0;
        
        const key = `${i},${j}`;
        if (memo.has(key)) return memo.get(key);
        
        let ans;
        if (text1[i] === text2[j]) {
            ans = 1 + helper(i + 1, j + 1);
        } else {
            ans = Math.max(helper(i + 1, j), helper(i, j + 1));
        }
        
        memo.set(key, ans);
        return ans;
    };
    
    return helper(0, 0);
};
```


## Complexity Analysis

| Approach | Time Complexity | Space Complexity | Notes |
| :--- | :--- | :--- | :--- |
| **Space-Optimized 1D DP** | $O(M \times N)$ | $O(\min(M, N))$ | Optimal. Compresses the matrix into a single 1D buffer of length $\min(M, N) + 1$. |
| **Full 2D DP Table** | $O(M \times N)$ | $O(M \times N)$ | Standard tabular solution; makes backtracking to reconstruct the LCS straightforward. |
| **Top-Down Memoization** | $O(M \times N)$ | $O(M \times N)$ | Recursion stack depth $M + N$ with memoization cache of size $M \times N$. |


## Edge Cases

- **No Common Characters (`text1 = "abc"`, `text2 = "def"`):** All entries resolve through mismatch branches; returns `0`.
- **Identical Strings (`text1 = "abc"`, `text2 = "abc"`):** Diagnonals match on every step; returns `3`.
- **Repeated Characters (`text1 = "aaaa"`, `text2 = "a"`):** Only one `'a'` can be matched; returns `1`.
- **One String is Subsequence of Other (`text1 = "abcde"`, `text2 = "ace"`):** Returns `3`.
