## Problem Statement

There is a robot on an `m x n` grid. The robot is initially located at the **top-left corner** (`grid[0][0]`). The robot tries to move to the **bottom-right corner** (`grid[m - 1][n - 1]`). The robot can only move either **down** or **right** at any point in time.

Given the two integers `m` and `n`, return the number of possible unique paths that the robot can take to reach the bottom-right corner.

The test cases are generated so that the answer will be less than or equal to $2 \times 10^9$.

**Example 1:**
```text
Input: m = 3, n = 7
Output: 28
```

**Example 2:**
```text
Input: m = 3, n = 2
Output: 3
Explanation: From the top-left corner, there are a total of 3 ways to reach the bottom-right corner:
1. Right -> Down -> Down
2. Down -> Down -> Right
3. Down -> Right -> Down
```

**Constraints:**
- `1 <= m, n <= 100`


## The 2D Dynamic Programming Intuition

### Defining the State and Recurrence
Let $\text{dp}[r][c]$ be the number of unique paths from the start `(0, 0)` to cell `(r, c)`.

Because the robot can only move **Right** or **Down**:
- The only way to enter cell `(r, c)` from the top is moving Down from `(r - 1, c)`.
- The only way to enter cell `(r, c)` from the left is moving Right from `(r, c - 1)`.

By the Addition Principle of combinatorics:

$$\text{dp}[r][c] = \text{dp}[r - 1][c] + \text{dp}[r][c - 1]$$

### Base Cases
- **Top Row (`r = 0`):** The robot can only reach cells in the top row by moving continuously to the right. Therefore, $\text{dp}[0][c] = 1$ for all $c$.
- **Leftmost Column (`c = 0`):** The robot can only reach cells in the first column by moving continuously downwards. Therefore, $\text{dp}[r][0] = 1$ for all $r$.

## Solution 1: 1D Space-Optimized DP ($O(M \cdot N)$ Time, $O(N)$ Space) - Recommended

Notice that computing cell `(r, c)` only depends on the current row's previous column (`row[c - 1]`) and the previous row's same column (`row[c]`):

```javascript
/**
 * @param {number} m
 * @param {number} n
 * @return {number}
 */
var uniquePaths = function(m, n) {
    // If grid is 1xN or Mx1, only a single straight-line path exists
    if (m === 1 || n === 1) {
        return 1;
    }
    
    // Initialize 1D DP array representing the top row filled with 1s
    const row = new Int32Array(n).fill(1);
    
    for (let r = 1; r < m; r++) {
        for (let c = 1; c < n; c++) {
            // row[c] currently holds the value from the row above (r - 1, c)
            // row[c - 1] holds the newly updated value from the left (r, c - 1)
            row[c] += row[c - 1];
        }
    }
    
    return row[n - 1];
};
```


## Solution 2: Full 2D Grid DP ($O(M \cdot N)$ Time, $O(M \cdot N)$ Space)

```javascript
/**
 * @param {number} m
 * @param {number} n
 * @return {number}
 */
var uniquePaths2D = function(m, n) {
    const dp = Array.from({ length: m }, () => new Int32Array(n));
    
    // Fill first row and first column with 1s
    for (let r = 0; r < m; r++) dp[r][0] = 1;
    for (let c = 0; c < n; c++) dp[0][c] = 1;
    
    for (let r = 1; r < m; r++) {
        for (let c = 1; c < n; c++) {
            dp[r][c] = dp[r - 1][c] + dp[r][c - 1];
        }
    }
    
    return dp[m - 1][n - 1];
};
```


## Solution 3: Combinatorics Formula ($O(\min(M, N))$ Time, $O(1)$ Space)

To travel from `(0, 0)` to `(m - 1, n - 1)`:
- You must take exactly $m - 1$ Down steps.
- You must take exactly $n - 1$ Right steps.
- Total moves: $(m - 1) + (n - 1) = m + n - 2$.

The answer is simply the number of combinations to choose $m - 1$ Down steps out of $m + n - 2$ total moves:

$$\binom{m + n - 2}{m - 1} = \frac{(m + n - 2)!}{(m - 1)! (n - 1)!}$$

```javascript
/**
 * @param {number} m
 * @param {number} n
 * @return {number}
 */
var uniquePathsMath = function(m, n) {
    const totalMoves = m + n - 2;
    const k = Math.min(m - 1, n - 1); // Minimize iterations
    
    let ans = 1;
    for (let i = 1; i <= k; i++) {
        ans = (ans * (totalMoves - k + i)) / i;
    }
    
    return Math.round(ans);
};
```


## Complexity Analysis

| Approach | Time Complexity | Space Complexity | Notes |
| :--- | :--- | :--- | :--- |
| **1D Space-Optimized DP** | $O(M \times N)$ | $O(\min(M, N))$ | Optimal practical solution. Fills a single 1D buffer. |
| **2D Dynamic Programming** | $O(M \times N)$ | $O(M \times N)$ | Direct translation of recurrence relation into an $M \times N$ matrix. |
| **Combinatorics** | $O(\min(M, N))$ | $O(1)$ | Pure mathematical formula using binomial coefficient $\binom{M+N-2}{M-1}$. |


## Edge Cases

- **$1 \times 1$ Grid (`m = 1, n = 1`):** Start is end; returns `1`.
- **Single Row (`m = 1, n = 5`):** Robot can only move Right; returns `1`.
- **Single Column (`m = 5, n = 1`):** Robot can only move Down; returns `1`.
- **Square Grids (`m = 3, n = 3`):** Symmetry preserves paths; returns `6`.
