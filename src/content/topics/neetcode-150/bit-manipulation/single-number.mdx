## Problem Statement

Given a **non-empty** array of integers `nums`, every element appears twice except for one. Find that single one.

You must implement a solution with a **linear runtime complexity** and use only **constant extra space** ($O(1)$).

**Example 1:**
```text
Input: nums = [2,2,1]
Output: 1
```

**Example 2:**
```text
Input: nums = [4,1,2,1,2]
Output: 4
```

**Example 3:**
```text
Input: nums = [1]
Output: 1
```

**Constraints:**
- `1 <= nums.length <= 3 * 10^4`
- `-3 * 10^4 <= nums[i] <= 3 * 10^4`
- Each element in the array appears twice except for one element which appears only once.


## The Trap: Why Hash Maps Fail the Constraints

Without space constraints, this problem is trivial with a Hash Table or Set:
- Count the frequency of each number ($O(N)$ space).
- Or toggle numbers in a `Set`: add on first encounter, delete on second ($O(N)$ space).

However, the problem explicitly demands **$O(1)$ auxiliary space**. To solve it without allocating dynamic memory, we turn to **Bit Manipulation**.


## Approach: XOR Bitwise Magic

The bitwise **XOR (`^`)** operator operates at the binary level, returning `1` if and only if the bits are different.

Three fundamental properties of XOR make it the perfect tool for this problem:
1. **Self-Cancellation (Inverse Property):**
   `x ^ x = 0`  
   *Any number XORed with itself cancels out to zero.*
2. **Identity Property:**
   `x ^ 0 = x`  
   *Any number XORed with zero remains unchanged.*
3. **Commutativity and Associativity:**
   `a ^ b ^ c = a ^ c ^ b = (a ^ b) ^ c`  
   *The order of operations does not matter.*

### The Grand Cancellation
If we XOR every number in `nums = [4, 1, 2, 1, 2]` together:
```text
result = 4 ^ 1 ^ 2 ^ 1 ^ 2
```

Because order does not matter (commutativity), we can conceptually regroup duplicate pairs together:
```text
result = (1 ^ 1) ^ (2 ^ 2) ^ 4
       = 0 ^ 0 ^ 4
       = 4
```

Every duplicate number pairs up and annihilates into `0`, leaving only the lone survivor!

## Solution

### Standard Loop

```javascript
/**
 * @param {number[]} nums
 * @return {number}
 */
var singleNumber = function(nums) {
    let result = 0; // 0 ^ x = x, making 0 the ideal accumulator seed
    
    for (const num of nums) {
        result ^= num;
    }
    
    return result;
};
```

### Functional One-Liner

```javascript
/**
 * @param {number[]} nums
 * @return {number}
 */
const singleNumber = (nums) => nums.reduce((acc, num) => acc ^ num, 0);
```


## Complexity Analysis

- **Time Complexity:** $O(N)$
  - We traverse the array of $N$ integers exactly once.
  - Bitwise XOR operations run in constant $O(1)$ hardware instructions.
- **Space Complexity:** $O(1)$
  - Only a single integer variable `result` is allocated in memory, satisfying the strict $O(1)$ constant space requirement.
