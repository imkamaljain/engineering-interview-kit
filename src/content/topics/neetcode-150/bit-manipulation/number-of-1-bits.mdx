## Problem Statement

Given a positive integer `n`, write a function that returns the number of set bits (also known as the **Hamming weight**) in its binary representation.

**Example 1:**
```text
Input: n = 11
Output: 3
Explanation: 
The binary representation of 11 is 1011, which has 3 set bits.
```

**Example 2:**
```text
Input: n = 128
Output: 1
Explanation: 
The binary representation of 128 is 10000000, which has 1 set bit.
```

**Example 3:**
```text
Input: n = 2147483645
Output: 30
Explanation: 
The binary representation of 2147483645 is 1111111111111111111111111111101, which has 30 set bits.
```

**Constraints:**
- `1 <= n <= 2^31 - 1`

**Follow up:**
If this function is called many times, how would you optimize it?


## Approach 1: Bit Shifting & Masking

Every integer in JavaScript is treated as a 32-bit signed sequence during bitwise operations.

To inspect the binary digits one by one:
1. Check the least significant bit (LSB) using bitwise AND: `(n & 1)`. If the LSB is `1`, increment `count`.
2. Shift all bits to the right using the **unsigned right shift** operator: `n = n >>> 1`.
   *(Note: Always use `>>>` rather than `>>` to ensure zeroes are shifted into the most significant position, avoiding unwanted sign bit preservation).*
3. Repeat until `n === 0`.


## Approach 2: Brian Kernighan's Algorithm ($O(\text{set bits})$)

Approach 1 always checks every position up to the highest bit (up to 32 iterations). Even for `n = 128` (`10000000`), it wastes 7 loops inspecting `0`s!

Can we skip all the `0`s and **only jump directly from one `1` bit to the next**?
Yes, using **Brian Kernighan’s Algorithm**:
$$n = n \ \& \ (n - 1)$$

### The Mathematical Magic:
When you subtract `1` from any binary number:
- The **lowest set bit (rightmost 1)** flips from `1` to `0`.
- All trailing `0`s to its right flip from `0` to `1`.
- All bits to its left remain completely unchanged.

When you compute $n \ \& \ (n - 1)$, the flipped bits cancel out to `0`, effectively **clearing the lowest set bit**:
```text
n       = 1 1 0 0  (12)
n - 1   = 1 0 1 1  (11)
-----------------------
n & n-1 = 1 0 0 0  (8)  <- The rightmost '1' was cleanly erased!
```

By repeating `n = n & (n - 1)` in a loop, each iteration eliminates exactly one `1` bit. The number of loop cycles equals the **exact number of set bits**!

## Solution

### Optimal: Brian Kernighan's Algorithm

```javascript
/**
 * @param {number} n
 * @return {number}
 */
var hammingWeight = function(n) {
    let count = 0;
    
    while (n !== 0) {
        // Clear the lowest set bit
        n = n & (n - 1);
        count++;
    }
    
    return count;
};
```

### Approach 1: Bit Shifting

```javascript
/**
 * @param {number} n
 * @return {number}
 */
var hammingWeightShift = function(n) {
    let count = 0;
    
    while (n !== 0) {
        count += (n & 1);
        n = n >>> 1; // Unsigned right shift
    }
    
    return count;
};
```


## Follow-up: High-Frequency Queries ($O(1)$ Table Lookup)

If `hammingWeight` is called billions of times in a real-time system, we precompute a lookup table for all 8-bit integers (`0` to `255`):

```javascript
// Precomputed table for 0-255 (2^8 values)
const POPCOUNT_TABLE = new Uint8Array(256);
for (let i = 0; i < 256; i++) {
    POPCOUNT_TABLE[i] = (i & 1) + POPCOUNT_TABLE[i >> 1];
}

function hammingWeightTable(n) {
    return (
        POPCOUNT_TABLE[n & 0xff] +
        POPCOUNT_TABLE[(n >>> 8) & 0xff] +
        POPCOUNT_TABLE[(n >>> 16) & 0xff] +
        POPCOUNT_TABLE[(n >>> 24) & 0xff]
    );
}
```
*Processes any 32-bit integer in constant $O(1)$ time with just 4 array lookups and bitmasks.*


## Complexity Analysis

- **Brian Kernighan's Algorithm:**
  - **Time Complexity:** $O(K)$ where $K$ is the number of set bits ($0 \le K \le 32$). In the worst case (all ones), it takes 32 iterations; for sparse integers, it takes only 1 or 2 steps.
  - **Space Complexity:** $O(1)$ auxiliary storage.
- **Bit Shifting:**
  - **Time Complexity:** $O(B)$ where $B$ is the position of the highest set bit ($B \le 32$).
  - **Space Complexity:** $O(1)$.
